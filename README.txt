# Rota Comercial — Joinville

Abra `index.html` em um navegador com internet.

O mapa usa Leaflet + OpenStreetMap. Os estabelecimentos são carregados dinamicamente da API Overpass conforme a área visível do mapa.

Recursos:
- mapa de Joinville
- estabelecimentos cadastrados no OpenStreetMap
- busca por nome
- filtro por categoria
- filtro visitado/não visitado
- marcação de visita
- data da visita salva no navegador
- contadores
- telefone/endereço/site quando disponíveis no OpenStreetMap

Observação: "todos os estabelecimentos" significa todos os objetos comerciais/POIs que o OpenStreetMap disponibilizar na área consultada e que estejam devidamente mapeados. Não representa necessariamente todos os estabelecimentos existentes em Joinville.

Os dados do OpenStreetMap são disponibilizados sob ODbL e a página mantém a atribuição exigida.
